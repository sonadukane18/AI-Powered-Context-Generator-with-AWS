# AI-Powered-Context-Generator-with-AWS
This project demonstrates how to build an end-to-end serverless Generative AI application on AWS that generates blog content using foundation models in Amazon Bedrock.  A REST API accepts a blog topic, invokes a foundation model to generate content.

Services Used - AWS Lambda, API Gateway, s3, Amazon Bedrock - Model: Meta Llama 3.3 70B Instruct model
Frontend static website - that they can host on s3 as well 
Features - Copy and Download the Blogs, in the backend all of them are stored on s3 itself with versioning
